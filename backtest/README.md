# 通道突破策略回测系统

## 概述

基于币安数据的5周期通道突破策略(Channel Break Out Strategy)回测工具，用于对比TradingView回测结果和实际币安数据回测的差异。

## 策略规则

- **周期**: 1分钟K线
- **通道**: 5周期最高价/最低价通道（Donchian Channel）
- **做多**: 价格突破5周期最高价
- **做空**: 价格突破5周期最低价
- **平仓**: 反向信号触发时平仓并反向开仓

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 运行基础回测
python3 channel_breakout_backtest.py

# 运行V2版本（对比多种模式）
python3 channel_breakout_backtest_v2.py
```

## 回测结果对比

### 2025年12月1日-12月12日回测结果

| 模式 | 净利润 | 收益率 | 说明 |
|------|--------|--------|------|
| 收盘价入场 | -$468 | -4.68% | 实际可执行的方式 |
| 理想入场价 | +$4,803 | +48.03% | TradingView风格 |
| TradingView显示 | +$47,713 | +4.77% | 100万初始资金 |

### 关键发现

1. **TradingView使用理想入场价格**: TradingView回测假设在突破瞬间以通道价格成交，这在实盘中几乎无法实现。

2. **收盘价入场导致亏损**: 如果等到K线收盘后再判断信号并入场，策略会亏损，因为突破后价格已经远离通道线。

3. **实盘预期收益会更低**: 考虑滑点、延迟、手续费等因素，实盘收益通常比回测低20-50%。

## 参数配置

在脚本中可以修改以下参数：

```python
symbol = "BTCUSDT"      # 交易对
interval = "1m"          # K线周期
channel_period = 5       # 通道周期
initial_capital = 10000  # 初始资金 (USD)
position_size = 0.1      # 单次开仓数量 (BTC)
fee_rate = 0.0           # 手续费率 (0 = 不考虑)
```

## 与TradingView差异分析

### 为什么结果不同？

1. **数据源差异**: TradingView和币安的数据可能有微小差异
2. **入场价格差异**: TradingView使用理论最优价格
3. **信号判断时机**: TradingView可能在K线内部就触发信号
4. **仓位计算方式**: 百分比仓位 vs 固定仓位

### 建议

- TradingView显示的是理想化回测结果
- 实际交易中收益通常低于回测
- 建议使用更保守的预期进行风险评估
- 先小仓位实盘验证再放大资金
