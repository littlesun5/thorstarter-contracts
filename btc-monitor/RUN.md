# 🚀 立即运行 BTC 价差监控器

## 一键启动（复制粘贴执行）

```bash
cd /workspace/btc-monitor && npm install && npm start
```

然后在浏览器访问: **http://localhost:3000**

## 详细步骤

### 步骤1: 进入项目目录
```bash
cd /workspace/btc-monitor
```

### 步骤2: 安装依赖（首次运行）
```bash
npm install
```

### 步骤3: 启动监控服务
```bash
npm start
```

### 步骤4: 打开浏览器
访问: http://localhost:3000

## 使用界面

### 开始监控
1. 点击 **"▶ 开始监控"** 按钮
2. 授权浏览器通知（首次使用）
3. 系统会自动开始监控价格

### 设置报警阈值
- **最小价差**: 默认 $10（价差小于此值时报警）
- **最大价差**: 默认 $80（价差大于此值时报警）
- **刷新间隔**: 默认 5 秒

### 报警提醒
当价差超出设定范围时，系统会通过以下方式提醒：
- 🔔 浏览器弹窗
- 📢 页面内提示
- 🔊 提示音
- 📝 记录到历史

## 测试API（可选）

运行测试脚本检查API状态：
```bash
./test-api.sh
```

## 停止服务

按 `Ctrl+C` 停止服务器

## 常见问题

### Q: 看到CORS错误？
A: 确保通过 `npm start` 启动了代理服务器

### Q: Lighter价格显示"获取失败"？
A: 当前Lighter API不可用，系统会使用模拟数据

### Q: 如何修改端口？
A: 编辑 `proxy-server.js` 中的 `PORT` 变量
