# 🚀 快速启动指南

## 方式一：通过代理服务器使用（推荐）

1. **安装依赖**
   ```bash
   cd /workspace/btc-monitor
   npm install
   ```

2. **启动服务器**
   ```bash
   npm start
   ```

3. **访问监控页面**
   打开浏览器访问: http://localhost:3000

## 方式二：直接打开HTML文件

直接在浏览器中打开 `index.html` 文件即可。

⚠️ **注意**: 由于浏览器CORS限制，直接打开可能无法获取实时价格数据。推荐使用方式一。

## 使用说明

### 监控设置
- **最小价差**: 当价差 < $10 时触发报警（默认值）
- **最大价差**: 当价差 > $80 时触发报警（默认值）
- **刷新间隔**: 价格更新频率，默认5秒

### 功能特点
- ✅ 实时显示两个交易所的BTC价格
- ✅ 自动计算价差并显示百分比
- ✅ 价差超出阈值时弹窗报警
- ✅ 图表显示价差历史走势
- ✅ 保存报警历史记录

### 报警方式
1. 🔔 浏览器弹窗通知（需授权）
2. 📢 页面内弹窗提示
3. 🔊 声音提醒
4. 📋 历史记录

## 常见问题

**Q: 为什么Lighter显示模拟数据？**
A: Lighter API端点可能已更改，当前使用基于Backpack价格的模拟数据进行演示。

**Q: 如何修改报警阈值？**
A: 在页面控制面板中直接修改"最小价差"和"最大价差"的值。

**Q: 图表显示多少历史数据？**
A: 默认显示最近50个数据点，自动滚动更新。
