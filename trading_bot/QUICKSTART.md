# 快速启动指南 🚀

## 5分钟快速上手

### 第一步：安装依赖
```bash
cd trading_bot
pip install -r requirements.txt
```

### 第二步：配置API密钥
```bash
# 复制配置模板
cp .env.example .env

# 编辑.env文件，填入你的API密钥
nano .env  # 或使用其他编辑器
```

在`.env`文件中填入：
```env
BACKPACK_API_KEY=你的API密钥
BACKPACK_SECRET_KEY=你的Secret密钥
DRY_RUN=true
```

### 第三步：测试连接
```bash
python test_connection.py
```

如果看到"所有测试通过"，说明配置正确！

### 第四步：启动机器人（模拟模式）
```bash
python main.py
```

机器人将开始运行，但不会实际下单（DRY_RUN=true）。

### 第五步：真实交易（可选）
⚠️ **风险警告**：仅在充分理解策略和风险后使用！

1. 修改`.env`文件：
```env
DRY_RUN=false
```

2. 启动机器人：
```bash
python main.py
```

3. 输入"YES"确认真实交易
